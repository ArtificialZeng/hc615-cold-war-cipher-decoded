# Protocol v1

CP000 locks target/source and integrity criteria. CP010 locks an independently reviewed occurrence-bearing source transcript, with ambiguous font/annotation distinctions retained. CP020 audits repeat/word patterns and cipher glyph classes. CP030 qualifies a bounded language/model solver on fresh independent synthetic controls with truth masked; controls must resemble source length/word boundary/alphabet assumptions. CP040 attacks the real unknown input using registered models/configs/seeds, saves every candidate and examines whole-text/accounting. Do not increase budgets or add per-position exceptions to rescue language fluency. CP050 independently falsifies promising whole-message candidate, exact roundtrip, source ambiguity and alternative keys. A source or software PASS is not a decipherment PASS.

Default next hypothesis, subject to source audit, is fixed monoalphabetic substitution with red annotations as word bounds. Distinct keyboard signs remain distinct cipher identities; no unmarked glyph merge. Test letter-language variants only with public source-grounded independent corpora and explicit orthographic normalization. A failed finite optimizer is not a family impossibility proof. No new source-free plaintext cribs.

Only a compact supported mechanism reproducing every target cipher sign from a coherent complete reading may be called solved. A conditional partial reading is reported as partial. Preserve uncertain slots and annotate any inferred accents or punctuation instead of treating restoration as historical observation. Checkpoints save immutable artifacts, configs/seeds/SHA256 and Git commit; tags require the precise checkpoint gate to pass. Continue automatically, or after bounded limit switch to a materially new actual puzzle/source route.
