# Review and contributions

Source criticism and falsification are welcome. Start with the [exact reading](docs/SOLUTION.md), [methods](docs/METHODS.md), [provenance](docs/PROVENANCE.md) and [claim limits](docs/CLAIMS.md). Run the verifier before proposing a change.

For a glyph objection, identify occurrence IDs and source coordinates, explain the shape distinction, and link the original provider. Do not paste redistributed source scan pixels into issues without the appropriate permission. For a competing reading, supply one consistent observed key and a complete 220-symbol forward account, not isolated fluent phrases. For a prior answer, give a dated primary reference or original course key.

Never overwrite the frozen result or source to improve English/Czech fluency. Proposed corrections belong in a new version with explicit provenance. Keep f/q/w/x encodings UNKNOWN until actual source evidence exists. Do not erase failed controls, editorial alternatives or earlier pending verdicts. A technical regression or new source should be tested at the level it affects; unnecessary full search reruns are not required.

Contributions retain the appropriate code/prose/data licence; upstream linguistic derivatives remain CC BY-NC-SA 4.0. No contributor or cited expert is claimed as an endorser without an actual agreed statement.
